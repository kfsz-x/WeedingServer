# 本地与线上联机实施计划

目标：保留当前本地联机，在同一个房间面板提供本地、线上标签；线上容量限制与停服消息有明确客户端反馈。

方案：沿用协议10并增加可选 networkMode、code 字段。房间内部仍是六位编号，显示为 L-/O-；本地支持原六位输入。独立服务器通过 WEEDING_MODE=online 启用容量管理，本地服务默认 local。拒绝准入不踢已有成员。停服广播给所有 WebSocket，HTTP 返回统一停服码；宕机超时退出。

- [x] 为容量、模式、停服编写失败测试，再实现监控和请求门禁。
- [x] 同步 Node 正式入口，增加部署环境配置和停服说明。
- [x] 客户端实现独立地址、标签、编号校验、跨场景传递和离线提示。
- [x] 验证 Node 全量回归、Unity 编译和核心状态转换，审查修改范围。

约束：不覆盖现有未提交工作；当前目录按用户指定直接修改。访客退出时不保存房主世界；房主保留自己的进度。突发宕机不能主动广播。云端更新包需部署方重新部署，任务不直接重启公网服务。

默认上限是可调试运行值，不是承载保证：5房、20人、进程512MiB、单核CPU85%、事件循环延迟100ms。资源压力连续3次才拒绝，恢复连续5次才重新准入；监控每秒采样。

验证：服务端25/25，配套27/27；策略10项；原生/WebGL编译；隔离Unity状态测试PASS。独立审查修正HUD编号前缀和部署online配置。未执行云重启及客户端打包。
