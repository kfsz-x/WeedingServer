# 房间管理后台实施设计与计划

用户已选定：查看房间、踢出客人、关闭指定房间。页面集成现有Node服务/admin，沿用部署，由另一个任务上传。

展示：开房时间/持续时长、房主/客人的公开玩家编号、心跳、每房累计接收/发送量与最近5秒平均速率、服务器容量资源。每3秒刷新，无客户端身份令牌泄露。
操作：管理员令牌登录，HttpOnly SameSite会话与CSRF校验；踢人/关房有明确确认。关闭/踢出通知对应WS客户端，HTTP通过短期撤销记录返回SESSION_ENDED。正常离房钱包由房主权威结转。
计量：HTTP实际消息体，WebSocket实际JSON消息（含主动推送），跳过内部虚拟HTTP，避免重复。含压缩后消息字节，不含TCP/TLS/握手等开销，不冒充云账单。
访问：管理密钥仅部署环境变量，默认禁用；会话不放URL或localStorage。私网/HTTPS或SSH隧道访问，部署说明提供隧道方式。无新端口/依赖。
